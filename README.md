# avalon-sdks

Polyglot client SDKs for integrating with the Avalon Protocol network-facing
API, one directory per language (C#, TypeScript, and others as they land).

Each SDK is a thin client generated/maintained against the protocol's schema
— the Rust reference SDK lives with the core protocol workspace instead,
since it's an in-workspace dependency rather than a wire-boundary client.

**Status:** staged placeholder, no SDKs migrated in yet.
